# Stop-Loss Trading Lab

A beginner-friendly trading practice app focused on **stop losses, lot size, risk, and fees** — from total novice to expert novice, explained simply.

- **Bilingual:** English / Austrian German toggle (defaults to German), including narrated audio lessons in both languages
- **12 lessons** with diagrams, worked examples, and explainer videos
- **Quizzes** with level gating (4/5 to advance)
- **Calculators:** lot size, risk visualizer, fee estimator
- **Practice Desk:** candlestick simulator (EUR/USD, Apple, Bitcoin) with trade journal and expectancy stats
- **TradingView companion guide** (position tool, alerts, paper trading, bar replay)

## View it

Published with GitHub Pages — open the live link from the repo's About section.

## Structure

- `index.html` — the whole app (single page)
- `assets/audio/` — English lesson narrations (`lesson-l01.mp3` … `lesson-l12.mp3`)
- `assets/audio/de/` — German lesson narrations
- `assets/images/` — lesson diagrams
- `assets/videos/` — level explainer videos
